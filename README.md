# FinCompare Demo

A static, Vercel-ready demo for a credit-card and personal-loan comparison website.

## Test locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. In Vercel, choose **Add New → Project**, import the repository.
4. Framework preset: **Other**.
5. Build command: leave empty.
6. Output directory: leave empty.
7. Deploy.

## Before public launch
- Replace the demo lender URLs in `script.js` with verified, approved application URLs.
- Replace placeholder fees/rates/benefits with current information and source dates.
- Add your actual business name, contact details, privacy policy, terms, consent/disclosure language.
- Do not collect PAN, Aadhaar, OTP, bank passwords, CVV or other sensitive financial credentials on this static demo.
- If you plan to collect leads and distribute them to lenders, implement the required consent, privacy, security, contractual and regulatory requirements for your business model.
